# La teva primera pàgina web

Guia pràctica en català per començar amb HTML, provar els canvis amb Live Server a VS Code i publicar el projecte a GitHub. Pensada per a l'assignatura d'Aplicacions web del CFGM SMX.

## Fitxers

- `index.html`: guia completa i adaptable a mòbil, amb exemples d'HTML, una xuleta d'etiquetes i activitats.

## Com obrir-la

Obre la carpeta a VS Code i fes clic amb el botó dret sobre `index.html`. Tria **Open with Live Server** per veure-la al navegador i actualitzar-la en desar.
